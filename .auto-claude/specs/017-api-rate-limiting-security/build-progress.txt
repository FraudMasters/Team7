=== KEY PATTERNS OBSERVED ===

Middleware Registration:
- Middlewares are added via app.add_middleware() in main.py
- Order matters: CORSMiddleware first, then custom middlewares
- Pattern: from middleware.X import XMiddleware; app.add_middleware(XMiddleware)

Router Registration:
- Routers are included via app.include_router()
- Pattern: app.include_router(module.router, prefix="/api/path", tags=["Tag"])
- All routers registered at the end of main.py after exception handlers

Authentication Pattern:
- Dependencies use FastAPI Depends() with database session injection
- Pattern: async def get_current_user(db: AsyncSession = Depends(get_db)) -> User
- Middleware can also handle auth by checking headers and adding to request.state

Rate Limiting Implementation:
- Tiered limits: standard (60/min), expensive (10/min), upload (5/min)
- IP-based tracking with Redis or in-memory fallback
- Headers: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset
- 429 response with Retry-After header when exceeded
