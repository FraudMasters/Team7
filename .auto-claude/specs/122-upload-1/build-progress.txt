Backend Security Issues Found:
1. requirements.txt:
   - PyPDF2==3.0.1 is VULNERABLE (CVE-2025-62708) - need >= 6.1.3
   - pdfplumber==0.11.4 has vulnerable dependency chain (CVE-2025-70559)
   - Missing defusedxml>=0.7.1 for XXE protection
   - Missing filetype>=1.2.0 for magic number validation

2. Upload endpoints (api/resumes/upload.py, api/batch.py):
   - File validation uses only extension, NOT magic numbers
   - file_validation.py exists with magic number validation but NOT called
   - No XXE protection in DOCX parser
   - No filename sanitization (path traversal risk)
   - SQLi risk - needs audit of ORM usage

3. Frontend duplication:
   - Upload.tsx - Single file upload page
   - BatchUpload.tsx - Batch upload page
   - ResumeUploadPage.tsx - Job-associated upload
   - ResumeUploader.tsx - Reusable component
